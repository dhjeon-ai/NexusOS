# ProjectOS Sync Checks

## Purpose

Prevent the operating docs and reusable rule packs from drifting away from the real repository behavior.

## When to run a sync check

- a component contract changed
- a task lifecycle rule changed
- a subagent rule changed
- a bootstrap template changed
- a reporting or exception rule changed

## What to verify

- the index still points to real pages
- component pages still match the live code structure
- task rules still match how the team actually works
- any packaged templates still reflect the current operating model
